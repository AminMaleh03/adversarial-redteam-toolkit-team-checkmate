## What this is

A single real run of the `emotion.oces` evaluation against both `emotion_v1` and
`emotion_v2` (the same two endpoints as `emotion.core`; OCES is authored against the
same frozen defenses, see `artifacts/benchmark_v6/PROVENANCE.md`'s "Defense freeze
point" section). OCES = Out-of-Coverage Evaluation Suite: additional paraphrase and
distractor cases authored by the team after the evaluated defenses were frozen. The
authors knew what the defenses were; this is not a blind or externally authored holdout.

Real, verified counts from `analysis/analysis.json`:

- Suite size: 21 seed baselines + 42 attacks (21 `oces.paraphrase` + 21 `oces.distractor`)
  = 63 planned cases per endpoint, both completed 63/63 (coverage rate 1.0).
- Drift: 18 eligible comparisons, 0 qualifying flips, on both `emotion_v1` and
  `emotion_v2` for this seed set.
- Findings: 0 finding groups on either endpoint for this seed set.
- Operational: 0 unhandled 5xx / timeouts / connection failures / service-unavailable /
  slow responses / info leaks / invalid input accepted, on both endpoints.
- OCES expectation statuses (from the `oces` block): 0 `meets_expectation`, 0
  `violates_expectation` on either endpoint for this seed set (the remaining cases are
  `excluded`/`unevaluable` per the pre-registered oracle rules in `attacks/metadata.py`).

Authored case content and its validity-tier census (0 GOLD, 50 SILVER, 32 REVIEW across
the combined emotion+sentiment OCES set of 82 cases; 42 of those are the emotion
paraphrase+distractor variants used here) live in
`attacks/data/oces/oces_review_sheet.csv`, which is unchanged by this run.
