METHOD & LIMITS

Read the result in context.

Clean baselineAttack libraryV1 / V2 runnerManifest + resultsAnalysisThis report

Four defenses, one shared model

  1. Length validation. Reject sequences over the model's limit before inference.
  2. Strict request types. Reject wrong types and unexpected fields.
  3. Scoped exception handling. Contain unexpected errors while preserving validation responses.
  4. Unicode and whitespace cleanup. Normalize text before inference.

No model retraining; no silent truncation. Prediction timeout: 10 seconds. Latency bands: under 2 seconds normal, 2 seconds up to the deadline slow, deadline reached timeout.

Interpretation limits

    {% for note in limitations %}
  • {{ note }}
    • {% endfor %}
  • Category failure rates and prediction-flip rates use different eligible denominators. A zero denominator is displayed as N/A.
  • Manifest and suite compatibility are supplied by analysis. The report validates the JSON interface; it does not independently replay requests or prove when the manifest was registered.
  • Timeouts establish that the request deadline was reached. These artifacts do not identify which server processing stage caused the delay.
  • Leak detection is based on signatures and does not establish the absence of all possible information leaks.
