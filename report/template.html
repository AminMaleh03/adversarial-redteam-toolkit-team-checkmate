METHOD & LIMITS

Read the result in context.

Pipeline

Clean baselineAttack libraryV1 / V2 runnerManifest + resultsAnalysisThis report

Baseline sentences are attacked once per category, sent to both endpoints under the same runner, then scored by the same analysis rules and rendered into this report.

Relevance · 15%

Four defenses, one shared model

  1. Length validation. Reject sequences over the model's limit before inference.
  2. Strict request types. Reject wrong types and unexpected fields.
  3. Scoped exception handling. Contain unexpected errors while preserving validation responses.
  4. Unicode and whitespace cleanup. Normalize text before inference.

V1 and V2 run the identical model; only V2 adds these four application-layer defenses. No retraining, no silent truncation. Prediction timeout: 10 seconds. Latency bands: under 2 seconds normal, 2 seconds up to the deadline slow, deadline reached timeout.
